# Stack Releases

Official Android release downloads for **Stack**, a personal strength-training app.

## Install

Open the latest GitHub Release and download the attached `.apk` file.

On Android, you may be asked to allow installs from the browser or from Stack itself. Android will always show the normal package-installer confirmation before an update is installed.

## Updates

Stack includes an in-app **Check for Updates** control. Released APKs are signed with the same permanent Stack signing key so future versions can update an existing signed installation without clearing app data.

The application source remains in a separate private repository. This public repository is only used to distribute signed release APKs and release notes.
